# Public Alpha roadmap

Short public view of what Public Alpha means and what comes next. Strategy summary: [open-core.md](./open-core.md).

**Tag:** `v1.0.0-alpha.7` · **Label:** Public Alpha (not “public beta” yet)

> Under **heavy active development**. This roadmap is directional; nothing here is a ship promise for the current tag.

---

## Now (Public Alpha)

| Capability | Entitlement | Maturity |
| --- | --- | --- |
| Project Vault + Secrets Vault | Free | Usable offline; still evolving |
| Trusted Folder | Free | Shipped |
| LAN Wi‑Fi P2P | Free (opt-in) | Pairing + Handoff verified; Step 5 deltas + firewall-ON still open |
| On-device vault importer | Free | First password-manager JSON path dogfood-ready; more formats planned |
| Pricing / Stripe storefront | — | Hidden |

## Next (toward public beta DoD)

1. Additional vault importer export formats (same preview → selective → import quality bar)
2. P2P incremental deltas + honest transport security close-out
3. Recovery Kit / guided restore
4. suchconfig.io downloads with signing / notarization honesty

## Later

- Further manager export formats only after a quality bar
- Linux / Windows parity smoke
- Context Exporter and other ROADMAP Phase 2+ items

## Explicitly out of initial open-core vision

W3C DID / Verifiable Credentials, SuchUtils as part of this desktop repo, cloud-hosted vault sync, browser autofill, and “wait until everything ships” before opening Public Alpha source.
